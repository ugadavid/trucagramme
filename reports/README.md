# Reports

Les rapports de mission sont rangés dans un sous-dossier portant l’identifiant de la mission, par exemple :

`reports/TG-001/rapport.md`

Les captures ou autres preuves pertinentes peuvent être conservées à côté du rapport.

Un rapport doit distinguer :
- ce qui a été réalisé ;
- ce qui a été vérifié ;
- les limites ou écarts connus ;
- les fichiers/commits produits.
