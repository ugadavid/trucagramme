# Missions

Ce dossier contient les briefs canoniques confiés à Codex.

Convention actuelle : `TG-XXX_description.md`.

Une mission :
- fixe un périmètre précis ;
- indique les références à consulter ;
- sépare ce qui est autorisé de ce qui ne l’est pas ;
- demande une vérification proportionnée ;
- exige un rapport dans `reports/` ;
- se termine par un arrêt pour validation humaine.
